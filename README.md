# Market Trending

A 股盘后复盘看板。数据层自动抓取，观点层用 chat 生成 —— **不需要任何 LLM API key**。

## 设计原则：事实与观点分离

| 文件 | 内容 | 来源 |
|---|---|---|
| `market.json` | 纯客观数据：指数、板块、资金流、涨跌停生态、龙虎榜、估值 | `update_data.py` 自动抓取 |
| `insights.json` | 纯主观内容：大师观点、风格判定、交易建议、股票池、事件解读 | chat 生成后粘贴回填 |

两者严格不混。**`insights.json` 不存在时，页面显示"暂无"占位，绝不用预置文案冒充当日结论。**

## 快速开始

```bash
python3 -m venv .venv && .venv/bin/pip install akshare   # akshare 可选，见下
.venv/bin/python update_data.py                          # 抓数据 → market.json
.venv/bin/python make_prompt.py                          # 生成提示词并复制到剪贴板
#   ↓ 粘进 Claude / ChatGPT，等它输出 JSON，复制回复
.venv/bin/python save_insights.py                        # 读剪贴板 → 校验 → insights.json
python3 -m http.server 8000                              # 打开 http://localhost:8000/
```

也可以完全在浏览器里完成第 2–4 步：打开页面 → 「AI大师观点」区域的**生成 / 更新洞察内容**面板 →
复制提示词 → 贴进 chat → 把回复粘回来。结果存在 localStorage，可导出为 `insights.json`。
分享给别人时对方不用装 Python。

## 依赖

只有 `akshare` 一个第三方依赖，而且是**可选**的：

- 装了：涨停/跌停/连板/炸板率走东方财富官方股池口径（`stock_zt_pool_em` 等），准确。
- 没装：这几项留空并在页面标注"数据缺失"，其余功能照常。

其他全部走标准库。

## 数据口径的两个坑

**1. 涨停统计不能用"涨跌幅 ≥ 9.8%"。** 那样会漏掉 20cm/30cm 品种，又混入涨了 9.9% 但没封板的股票。
2026-07-17 实测：近似口径数出跌停 649 家，官方跌停池只有 192 家，差 3 倍多。本项目用
`akshare_feeds.py` 走官方股池，并剔除退市整理股（它们天天涨停，会把连板高度顶到虚高）。

**2. Yahoo 对部分 A 股指数报价不准。** 2026-07-21 实测上证50：Yahoo 2827.67，新浪 2943.63。
所以 CN 指数取数顺序是 **东方财富 → 新浪 → Yahoo**，且每个数据源都带交易日校验，
日期对不上就标记为 stale 而不是当成今日数据。

## 数据新鲜度

外部接口会失败（东财 502 尤其常见）。抓取失败时脚本**沿用上次数据但打上标记**，
而不是静默顶替。`market.json` 里的 `fetchStatus` 记录每个板块的状态：

- `live` — 本次成功抓取
- `partial` — 部分条目沿用旧值
- `stale` — 整块沿用旧值
- `missing` / `fallback` — 无数据

页面顶部会把非 `live` 的板块列成黄色告警条，提示词里也会带同样的警告，
让模型不要把陈旧数字当今日事实。

## 合成指标的真实公式

- **板块强度** = `clamp(50 + 5 × 涨幅%, 0, 100)`。只由涨幅线性换算，不含资金流等其他信息。
- **情绪温度**（`app.js` 的 `getTemperature`）：

  ```
  50
  + (上涨家数 / (上涨+下跌) − 0.5) × 34
  + min(涨停, 90) × 0.16
  − min(跌停, 60) × 0.28
  − min(炸板率, 80) × 0.12
  + 四大指数平均涨幅 × 5
  → clamp(8, 92)
  ```

- **投委会共识 %** = 该标的被点名次数 ÷ 给出点名的大师人数。由前端从 `insights.json`
  的 `masters[].picks` **重新统计**，不采信模型自己写的百分比。

## 配置

- `config/masters.json` — 18 位大师的人设。提示词和校验共用这一份，改这里两边同时生效。
- `config/insights_schema.json` — `insights.json` 的结构契约。校验不通过则拒绝写入，
  并列出具体哪个字段错，可以直接把报错贴回 chat 让它修正。

可选环境变量：`NEWS_RSS_URLS`（逗号分隔的 RSS 地址）。
